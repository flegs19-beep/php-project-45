# Brain Games

Проект игр — набор небольших консольных приложений на PHP, оформленных как игры с вопросами и ответами.

```
- Игра «Проверка на чётность»
- Игра «Калькулятор»
- Игра «Наибольший общий делитель»
- Игра «Арифметическая прогрессия»
- Игра «Простое число»
```

Все игры запускаются через консоль (CLI), то есть работают непосредственно в терминале.

# Инструкция по установке

```
1. Установить Git Bash
2. Установить PHP 8.2, Composer 2.9
3. Клонировать репозиторий
4. Установить зависимости проекта через Composer
    4.1 В корне проекта выполнить:
        composer install
        Если команда проходит без ошибок, значит все зависимости установлены.
5. Запуск через Git Bash
    ./bin/brain-even
    ./bin/brain-calc
    ./bin/brain-gcd
    ./bin/brain-progression
    ./bin/brain-prime
6. Либо запуск через терминал PowerShell, CMD
    php bin/brain-even
    php bin/brain-calc
    php bin/brain-gcd
    php bin/brain-progression
    php bin/brain-prime
```

# Системные требования

```
1. Windows 10/11
2. PHP 8.2
3. Composer 2.9
4. Любой терминал (Git Bash, PowerShell, CMD)
```

# Проверка

```
Чтобы понять, что окружение настроено правильно, используйте команды для проверки версий PHP и Composer

php -v
composer --version
```
